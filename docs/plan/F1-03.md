## B. Scope

**In scope:** a global `roles` catalog (6 roles as data), tenant-owned `users` and `user_roles` tables with RLS,
encryption and lookup for phone and national ID, a users repository on top of `TenantDb` (no HTTP endpoints),
isolation tests, and a dev-only synthetic seed.

**Out of scope** (the executor must not add these): passwords, OTP, JWT, sessions, lockout (F1-04); permissions,
`can()`, guards, the permission matrix (F1-05); audit log, idempotency, outbox (F1-06); `carriers`, `carrier_id` on
users or roles, carrier-level RLS (F1-08); any HTTP endpoint for users (endpoints without RBAC guards would break
deny-by-default, GUIDELINES §6.2); driver profile, vehicles, documents (F4).
